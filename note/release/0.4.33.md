# Balatro v0.4.33 — 消耗品域对真版：妖术多彩 + 灵魂/黑洞获取规则（第 58 处修复族）

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。
> R128 真版核对战役第七域（消耗品 52）：塔罗 22/22 ✓、星球 12/12 ✓、幽灵 16/18 ✓，
> 修复 2 处（幽灵域）。

## 缺陷与真版规则（Spectral Cards Wiki）

1. **妖术（Hex）**：真版「Add **Polychrome** to a random Joker, destroy all other Jokers」；
   实现误为**负片**（REF bug——R17 逐行对照 REF 的经典盲区再现）。
2. **灵魂/黑洞获取规则**：真版二者**仅**经幽灵补充包以 ~0.3%/张 概率出现，商店与
   小丑/卡片产出的随机幽灵池**完全排除**；实现为全 18 张均匀（任何途径皆可出）。

## 修复

- `Consumables.hex`：`NEGATIVE → POLY`。
- `Data.SPECIAL_SPECTRALS`；商店幽灵位（Shop case 4）与 `RunState.gainConsumable("spectral")`
  产出池排除二者；`Packs` 幽灵包生成改为 `chance(0.003)→soul / chance(0.003)→blackhole /
  else pick(16)`。
- 塔罗 22（含命运之轮 1/4 基础概率✓、星/月/日/世界花色映射✓、死神左→右✓）与星球 12
  （含海王星兼皇家✓）全数与真版一致，零改动。
- **种子复现**：商店/产出池变化仅在幽灵牌组或幽灵产出路径（池 18→16 的 pick 映射变化属
  有意分歧域）；幽灵包生成新增两次 chance 消耗（仅幽灵包路径）；其余零影响，全部 golden 通过。
