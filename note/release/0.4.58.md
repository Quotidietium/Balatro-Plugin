# Balatro v0.4.58 — R142：优惠券域核对 + 天文学家小丑半失效修复

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。审计重启第六轮（R142）。

## 改动

1. **#73 天文学家小丑的「天体包免费」半失效**：astronomer 是**小丑**（经
   `flags.freePlanets` 生效，星球牌免费一半自 R130 起工作正常），但天体包免费的
   消费点误查 `vouchers.contains("astronomer")`——**券集合**永远不含该小丑 key
   （32 券清单无此条目，亦无任何牌组/挑战注入），该半效果自 R130 落地即死亡，
   与小丑 desc「商店与天体包中的星球牌免费」不符。修复：天体包计价改读
   `flags.freePlanets`（与星球牌同源；computeFlags 在小丑 debuff 时正确撤销）。
   附带：R130 旧测试 `RealJokerRealignmentTest.astronomer…` 曾以
   `s.vouchers.add("astronomer")` 注入券集合迎合坏实现——与实现同源的虚假锁定
   （R135 教训第二次现形），已改为生产语义（持有小丑）。
