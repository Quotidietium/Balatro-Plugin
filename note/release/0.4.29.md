# Balatro v0.4.29 — 租赁小丑经济对齐真版（第 54 处修复）

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。
> R124 应用 R122/R123 教训于**赌注域**：8 赌注效果逐项对真版核对（balatrowiki.org/w/Stakes），
> 效果全对（含 1.0.1f 后的橙/金语义）；追查中发现租赁贴纸经济参数与真版不符。

## 缺陷与真版规则

- 真版（Reddit/Steam/TV Tropes/Stickers）：租赁小丑**售价恒 $1**（"costs $1 to buy"，与基价
  无关）、**卖价恒 $1**（"sell for only $1"，蛋类 sellBonus 仍叠加）、持有每回合 -$3。
- 缺陷：实现为 `price = max(1, price-3)`（$5 小丑 $2 买）与 `cost/2`（$8 租赁卖 $4）。
  REF 同错（REF bug）。仅金注（stakeIdx 7）出现——标准局与全部 golden 零影响。

## 修复

- `Shop.makeJokerItem`：rental → price = 1（固定）。
- `RunState.sellValue`：rental → max(1, 1 + sellBonus)（固定 $1 + 成长叠加）。
