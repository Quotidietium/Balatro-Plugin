# Balatro v0.4.42 — P4 性能优化：计分管线 + 枚举列表缓存

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。性能优化战役第 3 个引擎改动轮。

## 改动（4 项，行为零变化）

1. `Data` 新增枚举缓存列表（HAND_TYPES/ENHANCEMENTS/SEALS/TAROTS/PLANETS/SPECTRALS），
   替换 12 处热路径的 `values()` 克隆 + `List.of(...)` 重建（商店/补充包/紫蜡封/消耗品等）。
2. `Engine.playHand`：查重/包含/移除改 `int[]` 两两比较（消除 HashSet 构造与
   `List<Integer>.contains` 逐次装箱）；出牌顺序仍为手牌顺序（等价论证见报告）。
3. `Engine.discard`：同上；cards 保持 cardIds 顺序（流消耗顺序敏感，保持原语义）。
4. `Card.hashCode`：`Objects.hash(id)` → `return id`（免 varargs 数组分配）。

## 性能（best-of-3 交错 A/B，vs 优化前基线，累计含 P2/P3）

几何平均 **1.643×**；fullRun **2.835×**（每局分配 10.1M→2.0M）；roundCycle 2.830×；
playHand 1.328×（装箱消除）；discard 分配 802→577B。新增 createRun 基准场景。

## 兼容性

- 行为保持双证据：458 测试全过 + 7 个确定性场景干净 JVM `sinkΔ` 逐位一致。
- `Data` 新增只读公开常量（向后兼容）；其余公开签名零变化。0.4.x 直接替换 jar。
