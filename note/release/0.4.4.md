# Balatro v0.4.4 — madworld 双 Boss 移植补全 + 事件口径修正 + 帮助文案对齐

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。本轮主题为「功能与表述一致性」：
> 逐项核对帮助注册表 / README / plugin.yml / Data 描述与实际行为，发现并修复如下问题。
> 完全向后兼容（普通局行为不变；madworld 恢复为 REF 原生行为）。

## 修复清单

| # | 问题 | 修复 | 严重性 |
|---|---|---|---|
| 1 | **madworld（疯狂世界）双 Boss 移植遗漏**：REF engine.js `chooseBoss` 在 `mods.doubleBoss` 下抽取 2 个不同 Boss 入队、击败第一个后无商店间隔立即接第二个；Java 移植只入队 1 个、链式推进为「0.5.0 TODO」桩——实际只打 1 个 Boss，与帮助文案「每底注2Boss」不符；且 boss 随机流少消耗 pick，madworld 种子与 REF 分歧 | `chooseBoss` 补第二次 pick（≠第一个 Boss，5 次尽力去重）；`endRound` 击败 Boss 队列非空 → `blindSelect`/`boss` 提前 return（跳过回合结束消息与商店）。逐字对齐 REF，随机流消耗一致 | 移植遗漏（功能与表述不符 + 种子分歧） |
| 2 | **AnteClear 事件口径错误**：双 Boss 挑战击败第一个 Boss 后 `phase=BLIND_SELECT`（底注未清空），旧逻辑按「Boss 盲注胜出」即发 `BalatroAnteClearEvent`/`onAnteCleared`——第三方过关奖励每底注重复发放 | 改判 `phase==SHOP`（endRound 开商店 = 底注真正清空）才发；普通局行为不变（Boss 胜出即开商店） | 事件语义缺陷（影响第三方奖励发放） |
| 3 | **top 帮助文案陈旧**：`/balatro top` 自 0.3.9 起为按玩家聚合排行（最高底注·通关次数），帮助仍写单局口径「通关 > 底注 > 时间」 | 分页帮助与单命令详情同步为聚合口径 | 文档与实现不符 |
| 4 | 双 Boss 转场无提示：击败第一个 Boss 后玩家只见盲注选择界面，不知为何没有商店 | GameSession.play 在双 Boss 转场时发送「第二个 Boss 出现：<名称>」（命令与全息出牌路径共用） | UX 缺陷 |

## 本轮复核确认一致 / 留档

- **plugin.yml**：aliases `[blt, joker]`、权限 `balatro.play`(true)/`balatro.admin`(op)、usage 串与 README 一致。
- **REF 描述的既有夸张（保持 REF 对齐，不改）**：madworld「没有大小盲注」（REF 实际有大小盲，仅 Boss 翻倍）、omelette「无法获得其他金钱来源」（实际仅无利息）、city15「商店始终满员」（REF 商店本就满员）——均为 REF data.js 原文，金色测试锁定，帮助简写与之保持一致。
- **引擎消息缓冲**（`RunState.messages` + `takeMessages`）当前无人消费：引擎事件文本不进聊天框（状态全部经全息牌桌呈现）。本轮为关键转场（双 Boss）补了专门提示；通用消息外显为后续 UX 议题，留档。
