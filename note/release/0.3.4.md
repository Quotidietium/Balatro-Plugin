# Balatro v0.3.4 — 修复手牌显示与命中盒错位（向下偏半张牌）

> 0.3.3 的 bug 修复版。基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。

## 修复

### 手牌显示向下平移半个牌高，对齐点击命中盒

**实机反馈**：手牌的可见文字块与点击命中区不匹配——点牌的**下半部分**才有反应（上半部分点空），即可见牌面相对命中盒偏上约半张牌。

**根因**：手牌用 `TextDisplay` 渲染，其文字从实体位置**向上生长**；而点击命中盒（`Interaction`）以实体位置为**中心**。两者垂直相差约半个牌高，导致可见牌面浮在命中盒上方。

**修法**：手牌 `TextDisplay` 的生成位置向下偏移 `CARD_H/2`（= `CARD_HH`），使可见牌面中心对齐命中盒中心。命中盒位置不变。

> 注：小丑 / 消耗品 / 商店 / 补充包卡同样用 `TextDisplay` + 居中 `Interaction`，理论上存在同类的（更小的）偏移；本版先修实机确认的手牌，其余待反馈后再按各自高度修正。
