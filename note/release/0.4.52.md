# Balatro v0.4.52 — P14 性能优化：消耗品/补充包路径

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。性能战役第三期第 3 轮。

## 改动（行为零变化，全部严格胜出：以更少工作替代）

1. **一次性流分段折叠**：`use:`/`pack` 流名内嵌严格递增序号（永不复现），原实现每次
   String 拼接 + HashMap 插入，且长局下缓存 Map 无界增长。现由 `Rng.streamUse/streamPack`
   从前缀态直接分段折叠建流（零字符串物化、零缓存插入），与旧路径**逐位等价**
   （`RngSegmentedStreamTest` 4 用例语义矩阵锁定；含 foldInt 先取模再转型的
   MIN_VALUE 溢出事故修复）。
2. **P10 池化快照补点 4 处**：Consumables 的 onUseTarot/onUsePlanet、Packs 的
   onPackOpen/onPackSkip（P10 只覆盖了 Engine，本轮回补）。
3. **targets 查重**：`new HashSet<>` → ≤3 元素两两比较（去装箱分配）。
4. **新增基准场景** `useConsumable`/`packOpen`（补齐消耗品/补充包测量面）；流名全量清点
   守卫（R106）扩展分段入口，白名单审计能力保持。
