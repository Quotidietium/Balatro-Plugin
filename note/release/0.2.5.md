# 0.2.5 发布说明（修订版）

- 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）
- 产物：`build/libs/balatro-0.2.5.jar`
- 性质：**修订版** —— 聊天框补充卡牌简介

## 改动

### 卡牌简介发到聊天框（全息空间有限，用聊天框补全说明）

1. **商店/补充包出现时**：自动把所有商品/卡的简介（名称 + 价格 + 完整 desc）批量发到玩家聊天框，便于判断购买/选择。
   - `RoundBoard.update` 检测到进入 `SHOP`/`PACK` 阶段时调用 `sendShopInfo`/`sendPackInfo`。
2. **右键功能卡**：发送该卡简介到聊天框。
   - 手里的小丑 / 消耗品（塔罗/星球/幻灵）：右键 → 查看简介（`infoFor` 返回 name+desc；为其新增 `Interaction` 命中盒，action `joker:<i>`/`cons:<i>`）。
   - 商店商品 / 补充包卡 / 优惠券：右键执行购买/选择后，再发该卡简介（确认）。
   - 手牌扑克牌：右键 = 选中（不发，全息已显示点数/花色/增强）。
3. `BoardListener.dispatch`：操作前先取 `infoFor`（基于当前状态），操作后发送简介。

### 沿用
- 点击机制：`Interaction` 实体 + `PlayerInteractEntityEvent`（0.2.4）。
- 选中上移半张牌高、音效、卡牌缩放（0.2.2~0.2.4）。
