## 缺陷（#55）与修复

- 真版：象形文字「**-1 Ante, -1 hand each round**」；岩画「**-1 Ante again,
  -1 discard each round**」。

  （REF 同 bug，R18 的「12 券逐行一致」是对 REF 一致而非真版——R122 教训第四次应验）。
- 修复：`applyVouchersPassive` 补 `hieroglyph→handsBase-1`、`petroglyph→discardsBase-1`
  （从基数重建无叠加）；desc 与 golden 同步。
- 标准局零影响：无券路径不触发；全部 golden 原样通过。
