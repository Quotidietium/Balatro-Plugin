# Balatro v0.4.40 — P2 性能优化：随机流层

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。性能优化战役第 1 个引擎改动轮
> （`perf/plugin-performance` 分支）。

## 改动（4 项，行为零变化）

1. **`StreamSource.stream()` 取流零分配**：`computeIfAbsent(name, lambda)` 每次调用新分配
   一个捕获 `runSeed` 的 lambda 实例（实测 16 B/op，每次 prob/rngInt 都走）——改为
   get/缺省创建/put，命中路径零分配。
2. **`Rng.Stream.range/pick/shuffle` 去 `Math.floor`**：`(int) Math.floor(x)` 对 x≥0 与
   `(int) x` 逐位等价（截断≡向下取整；next()∈[0,1) 保证非负）。
3. `Rng.seedHash` 去冗余 `String.valueOf`。
4. `Rng.randomSeedString` 字母表提为静态常量。

## 性能（best-of-3 交错 A/B，详见 note/report/perf/2026-08-16-P2-随机流层.md）

几何平均 **1.139×**；命名流查找 **2.000×**（16→0 B/op）；整局 +13.6%；回合循环 +18.2%。

## 兼容性

- 种子复现红线零触碰（流名/顺序/消耗次数不变；floor 等价有逐位论证）。
- 458 测试全过（含 54 黄金 + Rng 1248 逐值断言）。0.4.x 直接替换 jar。
- 新增 `benchmark/` 子项目（性能基准，8 场景固定种子方法论 + best-of-3 协议）。
