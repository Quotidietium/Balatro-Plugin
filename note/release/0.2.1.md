# 0.2.1 发布说明（修订版）

- 基线：Minecraft 1.21.11 / Paper API（运行于 Papo 服务端）
- 产物：`build/libs/balatro-0.2.1.jar`
- 性质：**修订版** —— 修复 0.2.0 实机发现的两个问题

## 修复（0.2.0 实机反馈）

### 1. 全息牌桌无法点击 / 右键无反应（严重）
- **根因**：0.2.0（及之前）用 `World.rayTraceEntities` 命中 `TextDisplay`。但 Display 实体的命中盒（AABB）极小，射线几乎永远命不中 → 右键无反应。
- **修法**：弃用 `rayTraceEntities`，改由 `RoundBoard.hitTest` 做**视线射线 × 板面平面**相交，再按**命中盒**判断落点。
  - 命中盒与视觉尺寸**解耦**，独立设大（卡牌 0.72×1.10、按钮 0.96×0.44），保证好点。
  - 板面 `forward` 水平化（牌桌正立悬浮），命中平面与实体位置平面一致。
  - 各阶段（回合/商店/补充包）在 reflow 时注册可点击元素的局部坐标 + 命中盒，`hitTest` 逆序取上层。
- `BoardListener` 改用 `board.hitTest` 派发动作（选牌/出牌/弃牌/购买/选择/重掷/下一回合/跳过）。

### 2. 牌太小
- 卡牌 `TextDisplay` 设 `Transformation` 缩放 1.5×（默认约 0.5 格高 → 约 0.8 格高），牌面更清晰。
- 间距/布局常量同步调整（`CARD_SPACING` 0.78、`CARD_HW/HH` 命中盒等）防放大后重叠。

## 可调常量（实机微调用，均集中在 `RoundBoard` 顶部）

- `CARD_TEXT_SCALE`（卡牌文字缩放，现 1.5；仍偏小可调大，注意 `CARD_SPACING` 防重叠）
- `CARD_HW`/`CARD_HH`（卡牌命中盒半宽/半高，现 0.36/0.55；点不中可调大）
- `FORWARD`（牌桌距眼睛距离，现 2.6）、`RANGE`（`BoardListener` 射线最大距离，现 6.0）
- 各 `*_Y`/`*_SPACING` 布局常量
