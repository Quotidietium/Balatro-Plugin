# Balatro v0.4.46 — P8 性能优化：构局路径分配削减

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。性能战役第二期第 1 轮（P8）。

## 改动（Engine/RunState，行为零变化）

1. `RunState.fullDeck` 预置 52 容量：消除构局 10→15→22→33→49 的 5 次扩容拷贝链
   （JFR 分配采样实测 ArrayList.grow 链占 playHand 场景分配 ~25%，构局为其主源）。
2. `startRound` 对 `drawPile`/`discardPile` 首回合单步 `ensureCapacity(fullDeck.size())`
   （`instanceof ArrayList` 下探，第三方替换 List 实现时自动跳过仅失优化）。
3. `computeFlags` 双缓冲：复用备用 HashMap（clear+重填），消除 gainJoker×N/回合等
   高频重算的每次 new HashMap；旧表停驻备用时内容冻结，「换新表」可观察语义不变。
4. `chooseBoss` 抽取池静态化：常规 23 / 终结者 5 两个共享不可变列表，替代每底注
   新建 ArrayList 逐个筛选（池内容仅取决于 showdown，pick 只读）。
