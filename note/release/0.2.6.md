# 0.2.6 发布说明（修订版）

- 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）
- 产物：`build/libs/balatro-0.2.6.jar`
- 性质：**修订版** —— 统一交互规则（Shift 看信息 / 右键使用）

## 改动

### 统一交互规则

| 操作 | 行为 |
|---|---|
| **直接右键** | 使用/操作：选中手牌、购买商品、选择补充包卡、**使用消耗品**、**出售小丑**、出牌/弃牌/重掷/下一回合/跳过 |
| **Shift + 右键** | 查看该卡简介（发到聊天框）；按钮等无简介的仍执行操作 |

- `BoardListener`：`PlayerInteractEntityEvent` 中读 `player.isSneaking()`；Shift 时若 `infoFor` 有简介则只发简介、不操作，否则执行操作。
- 各卡「使用」语义：
  - 手牌扑克牌 = 选中；商店商品/补充包 = 购买；补充包卡 = 选择；
  - **手里消耗品（塔罗/星球/幻灵）= 使用**（`useConsumable`，无目标时对自身生效，需目标的会提示）；
  - **手里小丑 = 出售**（`sellJoker`）。

### 简介覆盖更全

- `infoFor` 新增 **手牌扑克牌** 简介：花色点数 + 增强/版本/蜡封说明 + 是否失效（`playingCardInfo`）。
- 故 Shift+右键可查看：手牌、小丑、消耗品、商店商品、补充包卡、优惠券。

### 操作说明（界面 + 聊天框）

- 状态栏新增一行：`右键=使用/选中  Shift+右键=查看简介`。
- 牌桌生成时聊天框发送《操作说明》（直接右键/Shift+右键各做什么）。
- 商店/补充包出现时的提示语更新为 `直接右键=购买/使用 · Shift+右键=查看该卡简介 …`。

### 沿用
- 点击机制：`Interaction` 实体 + `PlayerInteractEntityEvent`（0.2.4）。
- 商店/补充包出现自动列出全部简介（0.2.5）。
- 选中上移半张牌高、音效、卡牌缩放。
