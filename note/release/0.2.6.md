# Balatro v0.2.6 — 首个发布版本

> 在 Minecraft 1.21.11（Paper / Papo 服务端）中实现的《小丑牌》(Balatro) 扑克构筑 Roguelike 插件。
> 本版为**首个发布版本**。

## ✅ 已实现

**玩法引擎（完整；54 项黄金测试对照原版逐项/逐手验证）**
- 13 种牌型判定、`chips × mult` 计分、small/big/boss 盲注、8 底注（ante）通关、无尽模式
- **150 个小丑**（全钩子、复制类蓝图/头脑风暴）、**28 个 Boss 盲注**、**24 个跳过标签**、**20 个挑战**
- 消耗品：**塔罗 22 / 星球 12 / 幻灵 18** 全效果；增强 8 / 版本 4 / 蜡封 4
- 商店（生成/购买/重掷/优惠券/补充包）、15 牌组、8 赌注（引擎层完整）
- **种子可复现**（同一种子 ⇒ 同一局）

**全息牌桌（世界内渲染，仅本人可见）**
- 右键 = 使用/操作；**Shift + 右键 = 查看简介**（发到聊天框）；手牌自动按点数整理
- 回合 / 商店 / 补充包 **全阶段全息可玩**，进入商店·补充包时自动列出全部简介

**扩展性与集成**
- 开发者 API：5 个自定义事件 + 经济/统计/排行榜/奖励 4 个服务接口（详见 `API.md`）
- Vault 经济集成（softdepend）、文件持久化统计 + 排行榜（`/balatro top`）

## ⚠️ 存在的不足 / 已知限制

1. **全息交互尚未经实机验证**：点击响应、卡牌尺寸、面板布局/朝向需在 Papo 1.21.11 服务端实测并微调（常量集中在 `RoundBoard`，可调）。**这是当前最大的不确定点。**
2. **牌组 / 赌注 / 挑战模式的命令入口未开放**：引擎已完整实现三者，但 `/balatro play` 目前固定为「红牌组 / 白注」，挑战模式暂无命令入口（后续版本开放）。
3. **卡牌为文字牌面**：以 TextDisplay 文字（花色 + 点数 + 角标）呈现，无贴图/资源包依赖（后期可升级为 ItemDisplay + 资源包）。
4. **消耗品「使用」有限**：需指定目标手牌的消耗品（如改写手牌的塔罗），用命令传目标更稳妥；全息右键为「无目标使用」。
5. **退出即弃，不存档续局**（设计决策）；界面与文本以**中文为主**，暂无多语言。
6. **性能未压测**：全息实体数量、并发局数未经大规模验证。

## 构建

`./gradlew build` → `build/libs/balatro-0.2.6.jar`（JDK 21，paper-api 1.21.11）。
