# Balatro v0.4.21 — 商店出售持有牌 + 消耗品出售确认 + Boss 效果全程显示

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。
> 本版修复一项用户体验缺陷（商店阶段无法出售持有的小丑/消耗品），并消除消耗品出售确认的不对称、
> 补强 Boss 效果描述的全程可见性。

## 问题诊断

1. **核心缺陷**：商店全息视图 `reflowShop` 调用 `clearRoundSlots` 隐藏了全部手牌/小丑/消耗品槽位，
   导致商店阶段玩家**看不到也点不到**自己持有的小丑/消耗品——只能靠文本命令 `/balatro sellj|sellc`。
   原版 Balatro 中商店界面持有的小丑/消耗品可见且可直接点击出售。
2. **消耗品无专用出售确认**：小丑右键弹出 `sendSellConfirm`（带 `[确认出售]` 按钮），
   消耗品右键只弹 `sendUseConfirm`（出售仅灰色提示文字、无按钮），不对称。
3. **`cmdSellConsumable` 缺 TOCTOU 防护**：`cmdSellJoker`/`cmdUse` 有期望身份校验（防列表变化后卖错），
   `cmdSellConsumable` 没有——新增消耗品出售确认按钮后必须补此防护。
4. **Boss 描述仅第 1 底注显示**：`sendRunInfo` 显示 `name — desc`，但 `promptBlindSelect`、
   `reflowBlindSelect`、`reflowRound` 只显示名称，玩家在做盲注选择决策时看不到 Boss 效果。

## 修复

### 一、商店阶段渲染持有小丑/消耗品 + 出售交互（核心）

- `RoundBoard.reflowShop`：不再 `clearRoundSlots`，改为只隐藏手牌槽（商店不出牌），
  **新增渲染持有小丑行（y=2.0）与持有消耗品行（y=-0.45）**，每张牌放置 Interaction 命中盒，
  承载 `joker:i` / `cons:i` 动作（复用现有动作名）。
- 牌面标注售价（`$X`），永恒小丑不标售价（不可售）。
- 商店状态栏提示更新为「右键卡片购买 · 右键持有小丑/消耗品出售 · 重掷 · 下一回合」。

### 二、消耗品专用出售确认对话框（消除不对称）

- `RoundBoard` 新增 `sendSellConsumableConfirm(Player, int)`，结构对齐 `sendSellConfirm`（小丑版）：
  标题 `━━ 确认出售 ━━` + 消耗品名称 + 描述 + 售价 + 可点击 `[确认出售]`（→ `/balatro sellc`）
  与 `[取消]` 按钮。
- `BoardListener.dispatch` 中 `cons:` 动作改为**按阶段区分**：
  SHOP 阶段 → `sendSellConsumableConfirm`（出售）；ROUND 阶段 → `sendUseConfirm`（使用，不变）。

### 三、cmdSellConsumable 补 TOCTOU 防护

- 第 3 参数携带期望 `kind:key`（与 `cmdSellJoker`/`cmdUse` 一致），
  确认后到点击前消耗品列表若已变化则取消，防止序号错位卖错。
- 手动输入不带标识则跳过校验（向后兼容）。

### 四、Boss 效果描述全程显示

- `BalatroCommand.promptBlindSelect`：Boss 盲注时追加一行 `Boss 效果：<desc>`。
- `RoundBoard.reflowBlindSelect`：状态栏 Boss 时追加 `Boss：<desc>` 行。
- `RoundBoard.reflowRound`：状态栏 Boss 回合时追加 `Boss：<desc>` 行。

### 五、信息与帮助文案同步

- `RoundBoard.sendShopInfo` 尾部提示：`直接右键=购买 · 右键持有小丑/消耗品=出售 · …`。
- `RoundBoard.sendControls` 操作说明：括号追加「出售消耗品」。
- `BalatroHelp` 新增「商店出售持有牌」页（第 12 页），更新 sellj/sellc 单命令详情。
- `BalatroCommand.sendHelp` 简要帮助商店标题改为「商店（可右键持有牌出售）」。

## 测试

新增/更新测试：
- `BalatroHelpPaginationTest`：新增页后每页仍 ≤ 6 行（自动遍历，无需改测试）。
- `BalatroHelpCommandTest`：补充 sellj/sellc 详情含「商店阶段」表述的断言。

引擎层出售逻辑（`RunState.sellJoker`/`sellConsumable`）已由既有测试覆盖，本版不改引擎层。

`./gradlew clean build`：全部测试通过（具体数量以构建输出为准）。

## 构建

`./gradlew build` → `build/libs/balatro-0.4.21.jar`（JDK 21，paper-api 1.21.11）。

## 兼容性

- paper-api 1.21.11（`compileOnly`），Vault softdepend 不变。
- 纯渲染/交互/文案改进 + 命令层防护加固；引擎层、`api/` 包、配置/存档/API 契约零变更。
- 0.4.x 直接替换 jar。
