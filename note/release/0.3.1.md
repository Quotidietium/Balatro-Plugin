# Balatro v0.3.1 — 选牌上限拦截（UX 补丁）

> 0.3.0 的 UX 修订版。基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。

## 改动

### 选牌上限拦截（全息）

此前全息选牌无上限检查，可选 6~8 张；选多了再点出牌/弃牌时，引擎虽返回"请选择 1-5 张牌"，但全息路径（`playSelected` 忽略返回值）无任何反馈 → 表现为"点击出牌/弃牌无反应"。

改为**在选牌这步拦截**（`RoundBoard.toggleSelect`，上限 `MAX_SELECT=5`，对齐引擎出牌/弃牌 1~5 张）：
- 已选满 5 张再点新牌 → **不作出反应**：不选中、不重渲染、不播音效；
- 同时在**聊天框提示**：「选牌上限为 5 张（出牌/弃牌最多 5 张），请先取消部分牌再选。」
- `toggleSelect` 返回是否生效，`BoardListener` 仅在生效时播选中音效。
