# Balatro v0.4.43 — P5 性能优化：回合/商店/整局生命周期

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。性能优化战役第 4 个引擎改动轮。

## 改动（4 项，行为零变化）

1. `Engine.computeFlags`：`flags()` 每小丑只调一次（原判空+取值双调，`Map.of` 双倍分配）。
2. `RunState.handLevels`：`LinkedHashMap` → `EnumMap`（迭代序=声明序，与原插入序一致）。
3. `Engine.startRound`：`drawPile` 复用容量（clear+addAll 替代每次 new ArrayList 拷贝）。
4. `RunState.gainConsumable` / `Shop.genShopItem`：过滤池迭代源改用 `Data.TAROTS/SPECTRALS`
   缓存列表（免枚举数组克隆）。

**有意不动**：`handPlayedCount` 保持 LinkedHashMap（mostPlayedType 平局裁决依赖插入序）；
jokers 快照保持逐次复制（钩子中途增删语义）。

## 性能（best-of-3 交错 A/B，本会话累计口径）

分配全线下降：createRun 6,582→**5,854** B、playHand 累计 15,638→**12,814** B、
shopGen 14,166→**13,073** B、每局 fullRun 垃圾稳定 **2.0M** B。时间增益进入噪声带
（该层 CPU 热点已不显著）。详见 note/report/perf/2026-08-16-P5-生命周期.md。

## 兼容性

458 测试全过；`handLevels` 字段类型仍为 `Map<HandType,Integer>`（EnumMap 兼容实现）；
`drawPile` 改为原地复用（字段身份属实现细节，内容语义不变）。0.4.x 直接替换 jar。
