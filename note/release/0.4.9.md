# Balatro v0.4.9 — 引擎深层审计（确认轮）+ Castle 轮换回归测试

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。本轮主题为「引擎深层复查——
> startRound/drawUpTo/Boss 效果施加路径 + HandEval 边界 + 20 条挑战 mods 施加点 +
> 小丑 per-round 状态」。**审计结论：引擎核心路径全部 REF 对齐、无新缺陷**；
> 本轮为「确认轮」，产出为补一条回归测试锁定已核验的不变量。

## 审计确认安全的路径（留档）

- **startRound / drawOne / drawUpTo**：`handSizeRound = max(1, …)` 防软锁；`drawOne` 在
  drawPile 空时返回 null、drawUpTo 循环 break（牌组耗尽安全）；Boss pre-draw/post-draw
  施加点完整（house/wheel/mark/pillar/花色失效/人头失效/翠绿叶/翠绿铃）。
- **28 个 Boss 效果**：逐一核对施加点全覆盖——
  water/needle/manacle/club/goad/head/window/plant/leaf/acorn（startRound），
  house/bell（post-draw），hook/ox/tooth/arm/eye/mouth/psychic/flint/heart（playHand），
  wheel/mark/pillar（drawOne），serpent/fish（drawUpTo），wall/vessel（blindTarget）。
  needle 在 voucher/flag 加成后覆盖 handsLeft=1（顺序正确）；serpent n=3 与 REF 死代码行等价。
- **HandEval 边界**：空牌返回 null；石头牌排除花色但永计分；splash 覆盖；四指同花顺/皇家
  独立判定 + 计分并集；A 可高可低。straightWindow 用 TreeSet 去重 + shortcut 间隔容差。
- **20 条挑战 mods**：ChallengeMods 加载器逐条 try（单条非法不崩）、未知 mod 忽略、
  资源缺失退化为无挑战；jokers/money 立即生效、handSize/handsSet 由 applyVouchersPassive 应用；
  牌组变体（erratic/checkered/allStone/abandoned/facesToStone/numbersToFaces）在 buildFullDeck 落地。
- **chooseBoss**：bossKey 跨底注重滚去重（首底注 null 不滚）+ madworld 双 Boss 入队，流消耗对齐 REF。
- **标签系统**：double 标签不复制自身、复制下一非 double 标签；nextShop.merge(extraVoucher) 可叠加；
  standard/buffoon 标签立即开包；流名 "tag" 顺序对齐 REF。
- **小丑 per-round 状态**：「每回合换目标」类（Ancient/Castle/Idol/MailIn）一致用 `onRoundEnd`
  换目标（endRound 在盲注胜出时调用）；CERTIFICATE 用 onRoundStart 加牌；积累型（Green/Fortune/
  Supernova/ToTheMoon）有意跨回合不重置；自毁型（Seltzer/Obelisk）自管理。
- **计分循环稳健性**：逐张牌重触发用快照 activeJokers + resolveCopy null 检查，
  对计分中小丑状态变更安全（现行小丑不在 onScoreCard 自毁）。
- **discard 路径**：相位/余量/1-5 张/去重/手牌归属全校验；紫色蜡封→塔罗（满槽静默失败）；
  onDiscard 快照迭代 + contains 守卫。

## REF-inherited 已知项（保持对齐，不改）

- **madworld 描述「没有大小盲注」**：REF data.js 原文，实际 mod 仅 `doubleBoss=true`（玩家仍打
  小/大盲），属 REF 作者表述不实；golden 锁定，保持对齐（Round 4 已留档）。本插件帮助简写为
  「每底注2Boss」更贴近实际行为。

## 新增测试

`CastleRotationTest` ×1：Castle 弃指定花色牌 → 永久 +3 筹码（弃非指定花色不加）；
onRoundEnd 重新抽花色（0~3）后累积筹码保留（不重置）；弃「新花色」继续 +3、弃其他不加。
填补「每回合换目标」类小丑的显式测试空白（此前仅 golden 隐式覆盖）。
