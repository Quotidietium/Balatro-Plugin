# Balatro v0.4.62 — R238：面朝下牌身份保密（#81）

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。审计轮 R238（mark Boss 镜头）。

## 改动（#81 身份泄露，src/main 变更）

**问题**：mark Boss「所有人头牌面朝下抽取」的隐藏机制被两个文本通道击穿——板面
正确渲染为「？」（RoundBoard.cardFace），但 ①`/balatro status` 的手牌行
（GameSession.cardLabel）显示真实花色点数；②Shift+右键简介
（RoundBoard.playingCardInfo）同样显示真实身份+增强/版本/蜡封。

**修复**：
- `GameSession.cardLabel`：facedown → `？`（与板面一致）。
- `RoundBoard.playingCardInfo`：facedown → 「面朝下的牌（内容未知）」，增强/
  版本/蜡封一并隐藏。

## 测试（+2，共 550 全过）

- `BossWaterNoDiscardTest` ×2（R238 附带）：water Boss 回合弃牌次数=0、弃牌被拒
  （文案指向水）、出牌不受限、目标类消耗品照常（与 psychic/bell 锁同构，补齐
  water 的引擎语义）。
