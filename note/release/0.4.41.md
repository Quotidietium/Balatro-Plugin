# Balatro v0.4.41 — P3 性能优化：牌型判定层

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。性能优化战役第 2 个引擎改动轮。

## 改动

`HandEval.evaluate` 算法重写（**行为逐字保持**）：TreeSet/LinkedHashMap/Stream/HashSet
churn → 平坦数组（int[15] 计数 / boolean[15] 出现位 / Card[n] 暂存 / EnumSet）。
组间点数降序、组内手牌原序、全部分支口径与计分牌选择次序逐字对齐；
rank 边界安全性有论证（非石头牌恒 2..14）。

## 性能（best-of-3 交错 A/B，vs 优化前基线，累计含 P2）

- handEval **3.660×**（366→100 ns/op），分配 1,497→**231** B/op（6.5×）。
- fullRun **2.239×**（2.61ms→1.16ms），每局分配 10.02M→**2.03M**（5×）。
- roundCycle 2.116×；几何平均（8 场景）**1.514×**。
- 详见 note/report/perf/2026-08-16-P3-牌型判定层.md。

## 兼容性

- 判定不消耗随机流，种子复现零影响；458 测试全过（Eval/FourFingers/混沌 + 全部黄金）。
- `HandEval.Result` 公开契约不变。0.4.x 直接替换 jar。
