# Balatro v0.4.53 — P15 性能优化：牌型判定草稿区 + 每回合一次性流

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。性能战役第三期第 4 轮。

## 改动（行为零变化）

1. **HandEval 原语草稿区**（ThreadLocal 单层）：`cnt/present/arr/window`（纯原语数组）
   池化复用、用前清零；`suited`/scoring/contains/Result 逃逸部分保持新鲜分配。
   判据：无引用写屏障 + 每次全量重写（缓存必热）+ evaluate 无重入——与 P10/P11 失败的
   引用列表池化划清边界。开发中事故（已修复+入库）：固定 5 长 window 在四指 4 长窗口下
   残留脏值被全长迭代消费（异花 A 误计分 / 独立 JVM 表现为 SFLUSH 两态）——按 len 分持
   `window4/window5` 修复，FourFingersTest 即守门。
2. **每回合一次性流分段折叠**：`"shuffle"+roundCount`/`"shopgen"+roundCount`（内嵌递增
   回合数永不复现）改 `streamRound(prefix)`——P14 分段折叠扩展，零字符串物化/零缓存插入。
3. 守门：`streamRoundSegmentedEquivalence`（矩阵×16 值逐位）；流名清点扩展；474 测试全过。
