# Balatro v0.3.3 — 使用/出售二次确认（防误触）

> 0.3.2 的 UX 补丁。基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。

## 改动

### 右键使用/出售卡牌改为二次确认

此前全息**直接右键小丑 = 立即出售**、**直接右键消耗品 = 立即使用**，易误触。改为先在聊天框弹出确认提示，给出基本信息 + 可点击的「[确认]」「[取消]」按钮：

- **右键小丑** → 「确认出售」提示：名称 · 说明 · **售价** · 永恒判定（永恒小丑直接提示不可售、不给按钮）；按钮 `[确认出售]`（→ `/balatro sellj`）/ `[取消]`。
- **右键消耗品** → 「确认使用」提示：名称 · 说明 · **可出售价** · 目标手牌提示；按钮 `[确认使用]`（→ `/balatro use`，无目标）/ `[取消]`。
- 按钮用 Adventure `ClickEvent.runCommand` 实现聊天框可点击；新增 `/balatro cancel` 作为取消按钮的回执（回「已取消操作。」）。
- `Shift + 右键` 查看简介（原行为）不变。

确认/取消后，实际操作仍走既有命令路径，牌桌随之刷新。

## 测试

- `./gradlew test`：70 测试全过（本改动在渲染/监听/命令层，未改引擎逻辑）。

## 构建

`./gradlew build` → `build/libs/balatro-0.3.3.jar`（JDK 21，paper-api 1.21.11）。

## 兼容性

- 同 0.3.2：paper-api 1.21.11（`compileOnly`），无 hard-depend，Vault 为 softdepend。
