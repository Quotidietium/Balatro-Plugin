# Balatro v0.4.44 — P6 性能优化：数据表/注册表查找层

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。性能优化战役第 5 个引擎改动轮。

## 改动（查找 O(n)→O(1)，异常口径不变）

1. `Data.Suit.byIndex`：values() 克隆+线性扫 → 静态数组下标（渲染层 11 处调用的高频路径）。
2. `Data.Planet.byHand`：线性扫 → 静态 Map。
3. `Data.packByKey`/`voucherByKey`/`deckByKey`：线性扫 → 静态 HashMap 索引。
