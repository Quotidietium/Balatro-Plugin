# Balatro v0.4.51 — P13 性能优化：Card 位打包（48→32B/张）

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。性能战役第三期第 2 轮。

## 改动（行为零变化，公开 API 逐字不变）

1. **Card 内部位打包**：可变状态（rank 6b | suit+1 3b | enh ord+1 4b | edition ord+1 3b |
   seal ord+1 3b | debuff/facedown/broken 各 1b）压入单个 int，对象 48→**32B**（−33%）；
   一副 52 张省 **832B/局**，整副牌遍历缓存密度提升。全部访问仍经既有 getter/setter；
   枚举解码走静态 values() 缓存数组。
2. **热路径快速谓词** `isEnh/isEdition/isSeal(枚举)`：位段 int 比较（无解码数组访问），
   与 `getter() == e` 恒等（守门测试全枚举×全组合锁定）。内部热点调用点切换 19 处
   （HandEval 过滤/scoreOneCard 全分支/held/玻璃/蜡封/isSuit/isStone）。
   首轮 A/B 曾现 handEval 0.931×/playHand 0.796× 解码回归，谓词修复后聚焦复测 1.011×/0.985×。
3. 新增 `CardPackingTest` 6 用例守门（域 roundtrip / 位独立性 / 石头转换 / 快速谓词恒等 /
  域内变异稳定），**469 测试全过**。
