# 0.2.4 发布说明（修订版）

- 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）
- 产物：`build/libs/balatro-0.2.4.jar`
- 性质：**修订版** —— 彻底重做点击机制

## 改动

### 点击机制改用 Interaction 实体（根治"点不到"）

0.2.1~0.2.3 用「手动射线-平面相交」（hitTest），代码层面数学正确，但实机仍点不到——
说明该机制在实机不可靠。本版彻底改用 **MC 1.19.4+ 专为「可点击全息」设计的 `Interaction` 实体**：

- 每个可点击元素（手牌/出牌/弃牌/商品/补充包/重掷/下一回合/跳过/优惠券）放一个**不可见的 `Interaction` 命中盒**，
  其 `width×height` 即原生点击区，玩家右键它**确定触发** `PlayerInteractEntityEvent`。
- 不再依赖 `TextDisplay` 极小的命中盒，也不再用手动射线/`rayTraceEntities`/`PlayerInteractEvent`。
- `Holo.interaction`：生成 Interaction（width×height 命中盒、私有可见 `setVisibleByDefault(false)`+`showEntity`、打 `balatro_i_<action>` tag）。
- `RoundBoard`：`placeInteraction(lx,ly,hw,hh,action)` 在板面局部坐标放命中盒（foot 在 `ly-hh`、中心在 `ly`），实体池复用，`hideExtraInteractions` 隐藏未用槽（零尺寸+去标签）。移除 `hitTest`/`clickables`/`Clickable`/`debugMiss`。
- `BoardListener`：改监听 `PlayerInteractEntityEvent`，命中 `Interaction`→解析 `balatro_i_` tag→派发（选牌/出牌/弃牌/购买/选择/…）。移除 `PlayerInteractEvent`+`hitTest`+诊断日志。

### 其余沿用 0.2.2
- 选中上移半张牌高（`SELECT_LIFT=0.5`）。
- 选中/出牌/弃牌音效（`UI_BUTTON_CLICK` 音量 1.0，各动作不同音调）。
- 卡牌 `Transformation` 缩放 1.5×。

## 命中盒尺寸（可调，集中在 `RoundBoard` 常量）

- 卡牌 `CARD_HW/HH` = 0.36/0.55（命中区 0.72×1.10）
- 按钮 `BTN_HW/HH` = 0.55/0.24（0.96×0.48）
- 商品 `SHOPCARD_HW/HH` = 0.6/0.4；补充包 `PACK_HW/HH` = 0.8/0.35
