# 游戏逻辑审计记录

> 目标：确保小丑牌游戏逻辑无错误。逐项复核 Java 引擎对照原版 JS + 联网核对真实 Balatro 规则。

## 已逐项核验无误（对照真实 Balatro）

- **手牌自动整理（0.2.0 新增）**：`Engine.sortHand` 按「点数降序、同点花色升序、石头置末」整理手牌，逐字对齐原版 `game.js sortHand("rank")`。在 `startRound`/`playHand`/`discard`/`refillHand`/`Consumables.use` 末尾调用，且均在 `stream.pick(hand)`（bell/hook 等）之后——避免与原版分流，种子可复现。计分按手牌位置从左到右，故展示与计分顺序一致（真实 Balatro 即手牌排序后从左到右计分）。黄金值已用「REF + sortHand」重生成，54 测试全过。
- **计分管线顺序**：基础牌型筹码/倍率 → 每张计分牌(点数+增强+版本+蜡封+重触发+onScoreCard) → 持有牌(钢铁×1.5+onHeld+哑剧重触发) → 独立小丑(onScore+版本) → 天文台 → 等离子平衡 → 取整。与 engine.js 一致。
- **等离子牌组**：chips+mult 取平均再相乘；盲注目标 ×2。([Fandom](https://balatrogame.fandom.com/wiki/Plasma_Deck))
- **蓝图/头脑风暴**：蓝图复制右侧、头脑风暴复制最左。([Blueprint](https://balatrogame.fandom.com/wiki/Blueprint))
- **幸运牌/玻璃/蜡封概率**：1/5、1/15、1/4；红蜡封重触发、金蜡封+$3。
- **经济**：盲注奖励(3/4/5)、剩余出牌+$1、利息(每$5计$1,上限5,基于结算前余额)、黄金牌+$3。
- **抽样小丑**（~25 个）：joker/greedy/lusty/fibonacci/scaryface/abstract/supernova/cardsharp/ridebus/green/icecream/runner/square/vampire/swashbuckler/stencil/seeingdouble/flowerpot/wee/triboulet/yorick/chicot/baron/moon/photograph/obelix 等——均与真实规则一致。
