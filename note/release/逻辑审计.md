# 游戏逻辑审计记录

> 目标：确保小丑牌游戏逻辑无错误。逐项复核 Java 引擎对照原版 JS + 联网核对真实 Balatro 规则。

## 发现并修正的错误（7 处）

| # | 位置 | 错误 | 修正 | 依据 |
|---|---|---|---|---|
| 1 | `Engine.applyJokerScore` | `ctx.joker` 在 `onScore` 之后才设置，导致多小丑时累积型小丑读错 extra（单小丑巧合正确） | 改为 onScore 前设置 ctx.joker | 对照 engine.js（JS 是先设 ctx.joker 再 onScore） |
| 2 | 玻璃牌破碎 | 仅占位 `addChipBonus(0)`，未真正销毁牌（错入弃牌堆） | Card 加 broken 标志，计分后从牌组移除 | engine.js `removeCardEverywhere` |
| 3 | Card Sharp | REF JS 误用 run 级 `handPlayedCount>1`（其 desc 写"本回合"），与真实规则不符 | 改回合级 `playedTypesThisRound.contains` | 联网核实：同回合内再次打出 ([Fandom](https://balatrogame.fandom.com/wiki/Card_Sharp)) |
| 4 | Supernova | REF JS 在 handPlayedCount 增量前读取 → 少 1（不含当前手） | 改 `count+1`（含当前手） | 联网核实：已出5次第6次给+6 ([Reddit](https://www.reddit.com/r/balatro/comments/1fodquf/)) |
| 5 | Four Fingers 同花 | REF JS 要求"所有非万能牌同花色"（need 仅降数量阈值不放宽异花色），与真实规则不符 | 同花只需 4 张同花色（第5张可异花色）；计分牌仅为同花色牌 | 联网核实 ([Fandom](https://balatrogame.fandom.com/wiki/Four_Fingers)) |
| 6 | Four Fingers 顺子 | REF JS `straightLen` 在 5 张时强制 5（四指失效）+ 顺子计分含异点牌 | straightLen=fourFingers?4:5；顺子计分=窗口内牌（异点牌不计，同点重复均计） | 联网核实：仅构成顺子的牌计分 ([Wiki](https://balatrowiki.org/w/Four_Fingers)) |
| 7 | To the Moon（奔月） | REF JS 误实现为「每剩余出牌 +$1」(onRoundEnd return handsLeft)，完全错误 | 改为额外利息 `money/5`（每 $5 额外 +$1，不受基础上限） | 联网核实 ([Wiki](https://balatrowiki.org/w/To_the_Moon)) |

## 已逐项核验无误（对照真实 Balatro）

- **手牌自动整理（0.2.0 新增）**：`Engine.sortHand` 按「点数降序、同点花色升序、石头置末」整理手牌，逐字对齐原版 `game.js sortHand("rank")`。在 `startRound`/`playHand`/`discard`/`refillHand`/`Consumables.use` 末尾调用，且均在 `stream.pick(hand)`（bell/hook 等）之后——避免与原版分流，种子可复现。计分按手牌位置从左到右，故展示与计分顺序一致（真实 Balatro 即手牌排序后从左到右计分）。黄金值已用「REF + sortHand」重生成，54 测试全过。
- **计分管线顺序**：基础牌型筹码/倍率 → 每张计分牌(点数+增强+版本+蜡封+重触发+onScoreCard) → 持有牌(钢铁×1.5+onHeld+哑剧重触发) → 独立小丑(onScore+版本) → 天文台 → 等离子平衡 → 取整。与 engine.js 一致。
- **等离子牌组**：chips+mult 取平均再相乘；盲注目标 ×2。([Fandom](https://balatrogame.fandom.com/wiki/Plasma_Deck))
- **蓝图/头脑风暴**：蓝图复制右侧、头脑风暴复制最左。([Blueprint](https://balatrogame.fandom.com/wiki/Blueprint))
- **幸运牌/玻璃/蜡封概率**：1/5、1/15、1/4；红蜡封重触发、金蜡封+$3。
- **经济**：盲注奖励(3/4/5)、剩余出牌+$1、利息(每$5计$1,上限5,基于结算前余额)、黄金牌+$3。
- **抽样小丑**（~25 个）：joker/greedy/lusty/fibonacci/scaryface/abstract/supernova/cardsharp/ridebus/green/icecream/runner/square/vampire/swashbuckler/stencil/seeingdouble/flowerpot/wee/triboulet/yorick/chicot/baron/moon/photograph/obelix 等——均与真实规则一致。
- **28 Boss**：高墙/紫罗兰(目标修正)、水/缝衣针/镣铐/花色失效/人头失效/翠绿之叶/琥珀橡子/房子/翠绿铃/车轮/标记/支柱/通灵者/眼睛/嘴/燧石/绯红之心/公牛/牙齿/手臂/钩子/贪蛇/鱼——均正确。
- **52 消耗品**：星球升级、塔罗(力量/死神/倒吊人/愚人复制…)、幻灵(妖术/安魂曲/黑洞…)——抽样正确。
- **牌组变体**：erratic/checkered/abandoned/allStone/facesToStone/numbersToFaces。
