# Balatro v0.4.56 — R140：services/持久化层复审（FileStats 崩溃撕裂自愈）

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。审计重启第四轮（R140）。

## 改动

1. **#70 FileStats 崩溃撕裂尾行自愈**：追加模式在「内容已 flush、换行未落盘」处崩溃
   （append + newLine 两次写之间的断电窗口）会留下**无换行尾行**——重启加载时残行被
   decode 拒绝（可接受），但下一次 `record()` 的追加会**直接拼接在残行尾部**：残行与
   首条新记录并成一条脏行，下轮加载时两条全丢（静默数据丢失）。修复：`load()` 检测
   文件末字节非 `\n` 即 `compact()` 归一化（每行恢复独立换行），崩溃形态完全自愈。
