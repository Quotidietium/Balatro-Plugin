# Balatro v0.4.0 — 图形界面开局向导（/balatro gui）+ 聊天帮助悬浮增强

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。在 0.3.9（60 轮审计）稳定基础上
> 新增 UX 功能，不改动任何引擎/渲染/会话逻辑，API 完全向后兼容。

## 一、开局向导 GUI（/balatro gui，别名 menu）

新增 `cn.quotidietium.balatro.gui` 包，用箱子界面替代复杂命令参数：

- **菜单流程**：`MAIN(模式) → DECK(牌组15) → STAKE(赌注8) → [CHALLENGE(挑战20)] → CONFIRM(确认/种子/开始)`。
  标准局跳过挑战页；确认页可回看修改任一项。
- **种子**：默认随机；确认页左键种子图标 → 聊天框输入（60 秒超时，`cancel` 取消），
  右键恢复随机。种子校验复用 `Rng.isValidSeed`（长度 1~32，字符集白名单）。
- **选中反馈**：当前选项附魔光效（`setEnchantmentGlintOverride`，1.20.5+ 数据驱动）+ 顶行信息条；
  点击配 `UI_BUTTON_CLICK` 音效（对齐牌桌交互惯例）。

### 安全与稳定性设计

| 风险 | 对策 |
|---|---|
| 物品被偷入/取出菜单 | 只认 `GuiHolder`（不认标题）；点击/拖拽一律 `setCancelled(true)`；玩家背包侧只拦截不响应 |
| 槽位映射错乱 | 渲染与点击分派共用 `GuiLayout` 单一映射（内容槽/返回/前进），单测覆盖互逆性 |
| 数字键/Shift/双击/拖拽 | 全部在取消范围内 |
| 点击处理异常 | 兜底 try/catch：记日志 + 提示 + 关界面，不逃逸到事件分发器 |
| 种子输入异步 | `AsyncChatEvent` 仅捕获文本，`runTask` 回主线程改状态；超时/命令(`/`开头)/退出自动结束等待；吞掉的输入不广播 |
| 状态泄漏 | 玩家退出清状态；`onDisable` 先 `closeAll()` 关界面再收会话 |
| 打开 GUI 期间用命令开局 | 开始按钮与 `/balatro gui` 均有 `isActive` 双保险 |
| 挑战模式漏选挑战 | `GuiState` 默认第 1 个挑战，任何时刻状态均「可开局」（单测断言） |

## 二、聊天帮助悬浮增强（HoverText）

- 新增 `command/HoverText`：把帮助文本中的 `/balatro <命令>` 令牌转换为
  **可悬浮**（该命令的标题、详细说明、用法与**使用举例**）+ **可点击**（回填命令到输入框）的 Adventure 组件。
  悬浮内容取自 `BalatroHelp` 注册表——文案仍只维护一份，不会漂移。
- 接入三处：`/balatro`（简要帮助，逐命令令牌化）、`/balatro help <页码>`（分页逐行 commandify）、
  `/balatro help <命令名>`（详情行内令牌同样可悬浮）。
- 未知命令名不生成悬浮/点击（安全兜底）；§ 颜色码经 `LegacyComponentSerializer` 保真。

## 三、同步更新（细节）

- `BalatroCommand`：新增 `gui`/`menu` 子命令分发、Tab 补全（SUBS）、类 javadoc 子命令清单。
- `BalatroHelp`：第 1 页加入 gui 指引；新增 `gui` 命令详情（含别名 `menu`）。
- `plugin.yml`：usage 串加入 `gui`。
- `BalatroCommand.sendRunInfo` 提为 `public static`，GUI 与命令层共用同一开局信息展示。
- 构建：测试类路径显式补 `net.kyori:adventure-bom:4.26.1`（与 paper-api 1.21.11 对齐），
  使 HoverText 可单测（paper-api 为 compileOnly 不进测试类路径）。

## 四、API 兼容性

- **零破坏**：`api/event`、`api/service` 未改任何签名；引擎/会话/渲染/服务层未改行为。
- 新增公开面：`BalatroPlugin.guiManager()`（开局向导管理器）、`BalatroCommand.sendRunInfo`（静态展示方法）、
  `gui/GuiState`（纯逻辑选择状态，可被第三方复用组装开局参数）。
- GUI 开局与命令开局走同一 `SessionManager.start` 路径，`BalatroRunStartEvent` 等 5 个事件照常触发。

## 测试
