# Balatro v0.3.0 — 完整玩法接线 + play 参数选模式 + help 分页

> 在 Minecraft 1.21.11（Paper / Papo 服务端）中实现的《小丑牌》(Balatro) 插件。

## ✅ 本版重点

### 1. play 命令支持参数选定模式（牌组 / 赌注 / 挑战 / 种子）

`/balatro play [牌组] [赌注] [挑战] [种子]` —— **参数顺序不限**，自动识别：

- 牌组名（15 种）：red/blue/yellow/green/black/magic/nebula/ghost/zodiac/abandoned/checkered/painted/anaglyph/plasma/erratic
- 赌注数字（0~7）：0 白注 … 7 金注（效果累加）
- 挑战名（20 种）：omelette/city15/rich/…/jokerless
- 其余视作种子（向后兼容旧 `/balatro play <种子>`）

例：`/balatro play blue 1`、`/balatro play red 0 omelette`、`/balatro play erratic 7 HARDSEED`

至此 **15 牌组 / 8 赌注 / 20 挑战全部可玩**（此前固定为红牌组/白注，挑战无入口）。

### 2. help 命令（分页 + 单命令详情）

- `/balatro help [页码]` —— 聊天框分页显示完整玩法（开始/牌组/赌注/挑战/回合/商店/消耗品/出售排行/全息交互/计分要素，共 11 页，**每页 ≤6 行**）。
- `/balatro help <命令名>` —— 显示该命令的详细说明（用法/参数/示例），如 `/balatro help play`、`/balatro help pc`（支持别名）。
- 参数为数字→分页；为命令名→命令详情；未知命令提示。Tab 可补全页码与命令名。

### 4. 盲注选择与跳过标签（会话层接通）

此前 `GameSession` 在盲注选择阶段**自动推进**，玩家无法手动跳过盲注（标签系统不可达）。
本版改为：离开商店后停在**盲注选择阶段**，玩家可选择：

- `/balatro go` 或全息右键「▶ 开始」——开始当前盲注；
- `/balatro skip` 或全息右键「✗ 跳过」——跳过并获 1 个随机标签（Boss 不可跳过）。

引擎的 `selectBlind(skip)` + 24 个跳过标签效果自此全部可达。第一手盲注（`/balatro play` 后）与无尽模式入口仍自动开始，不强制选择。

### 5. 手牌比例固定为 1:0.62（竖向扑克牌，视觉美观）

- **牌面单元尺寸**精确为 高:宽 = 1:0.62：`CARD_H=1.10`、`CARD_W=0.682`（=0.62×高），命中盒与牌位布局据此（`CARD_HW/CARD_HH` 由其导出）。
- **渲染牌面宽度**：`TextDisplay` 可见宽度随文字内容自适应，短文字（2~3 字符）显示偏窄。改为每行牌面用空格**补到固定显示宽度** `CARD_TEXT_COLS=5`（半角=1，符号/中文=2，居中补白），使背景色块统一变宽、所有牌宽高一致，呈 高:宽=1:0.62；牌面统一 3 行（版本/点数/蜡封 · 花色 · 失效或增强）。
- **实机调参**：若仍偏窄/偏宽，只改 `CARD_TEXT_COLS`（增大变宽、减小变窄）即可，无需动其他代码。

### 6. 选牌上限拦截（UX）

此前全息选牌无上限，可选 6~8 张；选多了再点出牌/弃牌时引擎虽拒绝但全息无反馈（"无反应"）。改为**在选牌这步拦截**：已达 5 张上限再选新牌时，不选中、不重渲染、不播音效，仅在聊天框提示「选牌上限为 5 张」。
