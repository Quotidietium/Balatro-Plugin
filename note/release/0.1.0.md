# 0.1.0 发布说明（草稿）

- 基线：Minecraft 1.21.11 / Paper API（运行于 Papo 服务端）
- 产物：`build/libs/balatro-0.1.0.jar`
- 性质：**首个可玩版** —— 引擎核心 + 全息回合骨架

## 范围

- 引擎纯逻辑移植（`engine/`）：`Rng`(种子复现)、`Data`(花色/点数/13 牌型/盲注目标分)、`model`(Card 等)、`Engine`(牌型判定、chips×mult 计分、抽/出/弃、回合循环、small/big/boss 盲注、8 底注通关)。
- 预留扩展 API（`api/`）：自定义事件 + 服务接口。
- 会话：`/balatro play [牌组] [赌注] [种子]`，每人独立单局，退出即弃。
- 全息渲染：`RoundView`（TextDisplay 文字牌面），布局配置化，私有可见，射线交互 + 节流。
- 内容子集：~15 个基础小丑（覆盖各钩子类型）。

## 不含（后续版本）

商店 / 补充包 / 塔罗星球幻灵 / 增强/版本/蜡封 / 优惠券 / 标签 / 全部 Boss / 全部小丑 / 挑战 / 数据外置 / 经济排名。
