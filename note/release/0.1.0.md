# 0.1.0 发布说明

- 基线：Minecraft 1.21.11 / Paper API（运行于 Papo 服务端）
- 产物：`build/libs/balatro-0.1.0.jar`
- 构建环境：本地 JDK 21（`F:/Java/21`，`org.gradle.java.home` 固定）；Gradle 9.4.1 wrapper（复用 Papo 缓存）
- 性质：**首个可玩版** —— 引擎核心 + 全息回合骨架 + 预留扩展 API

## 已实现

### 引擎（纯逻辑，零 Bukkit 依赖，26 个 JUnit 黄金用例全过）
- `Rng`：逐 bit 移植 FNV-1a + mulberry32 + 命名流（**种子可复现**，黄金验证与原版 rng.js 逐值一致）。
- `Data`：花色/点数/13 牌型(基础+每级成长+order)/盲注目标分(底注表+倍率+奖励)/增强(8)/版本(4)/蜡封(4)/Boss(28，命名+复现)。
- `Card`：唯一 id + rank/suit + 可变 enh/edition/seal/chipBonus/debuff/facedown。
- `Engine`：createRun/chooseBoss/blindTarget/selectBlind/startRound/drawOne·drawUpTo/playHand(chips×mult，含增强/版本/蜡封/重触发/持有钢铁/小丑结算/plasma 平衡)/scoreOneCard/discard/endRound/proceedToNextBlind/continueEndless。
- `HandEval`：13 牌型判定（A 低顺/broadway/同花顺/皇家/四条等）+ 计分牌选择。
- 黄金用例：`rng.txt`/`data.txt`/`eval.txt`(15)/`engine.txt`(3 种子整回合)/`jokers.txt`(8 小丑整回合)，全部对照原版网页 JS 断言。
- `BasicJoker`：15 个基础小丑（joker/greedy/lusty/wrathful/gluttonous/jolly/zany/sly/wily/half/banner/summit/misprint/raisedfist/crafty）+ `JokerRegistry`。

### 会话 / 命令 / 事件
- `GameSession`/`SessionManager`：每玩家独立单局，退出即弃，自动推进盲注；在计分/盲注结算/底注通过/本局结束节点触发事件并调用服务。
- `/balatro` 命令：`play [seed] | playcard <索引…> | disc <索引…> | status | endless | quit`（文字交互，UI 前后均可玩）。
- `PlayerQuitEvent` 自动清理。

### 预留扩展 API（`api/`）
- 事件：`BalatroRunStartEvent`(可取消)/`HandScoreEvent`/`BlindResultEvent`/`AnteClearEvent`/`RunEndEvent`。
- 服务接口：`EconomyService`/`StatsService`/`LeaderboardProvider`/`RewardService` + 默认实现（NoOp/Memory）+ `Services` 注册表（运行期可替换）。

### 全息渲染 + 射线交互
- `RoundBoard`：TextDisplay 全息牌桌（状态栏/小丑行/手牌/出牌弃牌按钮），玩家眼前前向基定位，CENTER 朝向，私有可见（仅本人），选中态高亮。
- `BoardListener`：右键 `World.rayTraceEntities` 命中板面实体 → 选牌/出牌/弃牌，150ms 节流，点击音效。
