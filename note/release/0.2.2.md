# 0.2.2 发布说明（修订版）

- 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）
- 产物：`build/libs/balatro-0.2.2.jar`
- 性质：**修订版** —— 选中反馈增强 + 点击诊断

## 改动（0.2.1 实机反馈）

### 1. 选中/出牌/弃牌音效
- `UI_BUTTON_CLICK` 音量 0.6 → **1.0**，确保明显可闻。
- 选中牌（高音 1.6）、出牌（1.2）、弃牌（0.8）、购买/选择/重掷/下一回合/跳过各有音调。

### 2. 选中上移改为「半张牌高」
- `SELECT_LIFT` 0.25 → **0.5**（约半张牌高），选中态视觉更显著。
- 命中盒随之同步上移（`clickables` 用选中后的 y 注册），点选位置与视觉一致。

### 3. 「点不到」诊断日志
- 右键未命中（或无 session/board）时向服务端日志打印 `[Balatro-DBG] ...`，
  含 `denom`（视线-板面朝向）、`t`（距离）、`rx/ry`（落点局部坐标）、`clickables` 数、`nearest`（最近元素及归一化距离）。
- 用于精确定位"右键无反应"：若日志显示 `denom` 异常 → 视线未朝牌桌；`nearest dist` 略大于 1 → 命中盒偏小；`clickables=0` → reflow 未注册。
- 命中时静默（不刷屏）。
