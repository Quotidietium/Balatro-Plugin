# Balatro v0.4.24 — omelette 禁入券/小丑清单（真版对齐收尾）

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。
> 承接 0.4.23（用户拍板「对齐原版机制」）：补齐真版煎蛋卷（The Omelette）的
> banned vouchers/jokers 清单——R102 记录的最后一个真版差距。

## 真版规则（balatrowiki.org）

- **禁入券**：Seed Money（种子基金）/ Money Tree（摇钱树）——不进商店券池。
- **禁入小丑**：To the Moon（奔月）/ Rocket（火箭）/ Golden Joker（黄金小丑）/ Satellite（卫星）
  ——不进商店小丑位与随机获得路径（回合结算经济类，与三重金钱封禁配套）。

## 实现

- `Mods` 新增 `bannedVouchers`/`bannedJokers`（HashSet，空 = 无禁入）。
- `ChallengeMods` 新增 case `banVouchers=`/`banJokers=`（逗号清单）。
- 消费点三处：`Shop.genShop` 券池过滤、`Shop.makeJokerItem` 小丑池过滤、
  `RunState.gainRandomJoker` 池过滤（wraith/soul/补充包 buffoon 经 makeJokerItem 自动覆盖）。
- `challengemods.txt` omelette 块追加两条；`Data.java` desc 尾注「经济类券/小丑禁入」；
  BalatroHelp 同步；golden（data.txt omelette 行 / challengemods.txt omelette 块）同步
  ——有意分歧标记增至 5 处，gen-golden 再生成仍需手工重施加（同 0.4.23 警示）。

## 种子复现影响

- 标准/其余 19 挑战：**零影响**（禁入集为空，过滤为 no-op，池与 pick 索引不变）。
- omelette 局：券/小丑池缩小（选择集变化，next() 次数不变）——属 R102 有意分歧域。

## 测试

- `ChallengeRealMechanicsTest` 新增 `omeletteBannedEconomyContentNeverOffered`：
  禁入清单装载断言 + 随机小丑路径 400 抽 / 商店 60 家的券与小丑位收集，
  三路径与禁入集**全不相交**（非空性防过滤误伤全池）。
- `./gradlew test`：**370 全过**（0 失败 0 跳过）。

## 兼容性

- 行为变化仅 omelette 挑战（真版对齐）；其余玩法/API/配置/存档零变更。0.4.x 直接替换 jar。
