## 本轮复核确认安全的点（命令层 / 会话 / 渲染 / 迁移）

- **出牌/弃牌约束由引擎兜底**：`Engine.playHand`/`discard` 均强制 1~5 张 + `HashSet` 查重 + `findInHand` 归属校验；命令层 `parseIndices` 不查重不构成漏洞（篡改客户端构造的重复/超量 id 被引擎拒绝）。
- **全息选牌**：`RoundBoard.toggleSelect` 上限 5 张 + `findInHand` 拒绝陈旧/伪造 id；`ownsInteraction` 归属校验防跨玩家点击。
- **出售/使用**：`RunState.sellJoker` 永恒拦截 + 越界拦截；`sellConsumable` 越界拦截。
- **会话**：`SessionManager.start` 种子兜底校验 + `putIfAbsent` 开局重入防护；`endIfCurrent` 防 RunEnd 事件重开误杀新局。
- **迁移**：`BoardMoveListener` 世界判定先于距离平方（防跨世界异常），延迟 1 tick 取眼位；`RoundBoard.relocate` 保留选中牌；`update` 自愈（核心实体失效即重建）。
- **实体生命周期**：`Holo` 生成物全部非持久 + `balatro_board` 统一标签 + 私有可见；`despawn` 全量回收（含 Interaction 命中盒池）。

## 已知次要项（不修复，留档）

- `relocate` 后重发操作说明与商店/补充包简介（聊天框刷屏数行，信息仍正确）。
