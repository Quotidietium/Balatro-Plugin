# 0.2.0 发布说明

- 基线：Minecraft 1.21.11 / Paper API（运行于 Papo 服务端）
- 产物：`build/libs/balatro-0.2.0.jar`
- 构建环境：本地 JDK 21（`F:/Java/21`）；Gradle 9.4.1 wrapper
- 性质：**全息牌桌可点击卡牌化 + 手牌自动整理**（UX/渲染大改 + 引擎排序）

## 本版重点：直观可点击的排列手牌

> 解决 0.1.0 的痛点：手牌等需用指令打出、且不按点数排列。

### 1. 手牌自动按点数整理（引擎层）
- 新增 `Engine.sortHand`：点数降序、同点花色升序、石头牌置末，**逐字对齐原版 `game.js sortHand("rank")`**。
- 在 5 个手牌变动点调用：`startRound`（初抽 + bell pick 之后）、`playHand`（drawUpTo + updateBellCard 之后）、`discard`、`refillHand`、`Consumables.use` 末尾。
  - **调用时机红线**：均在 `stream.pick(hand)`（bell/hook 等）之后，避免与原版分流，保证种子可复现。
- 计分按手牌位置从左到右（`playHand` 内 `cards.sort(indexOf)`），故**展示与计分顺序一致**——玩家看到的排列就是计分顺序。
- 黄金值同步：`gen-golden.mjs` 在 `selectBlind` 与每次 `playHand` 后施加相同 `sortHand`，重生成 `engine/boss/jokers` 黄金值；**54 测试全过，种子可复现性保持**（Java 与 REF+sort 逐值一致）。

### 2. 全息牌桌重构为稳定卡牌实体（渲染层）
- `RoundBoard` 改为**持久槽位实体**：状态栏 / 按钮 / 手牌 / 小丑 / 消耗品 / 商店 / 补充包均为原地改写文本/背景/位置/标签，**不再 clear+respawn → 选牌、补牌、买卖均不闪烁**。
- **卡牌化外观**：每张牌以带背景色的色块呈现（点数 + 花色 + 增强/版本/蜡封角标）；选中时改绿色背景并**向上抬起**；翻面/失效/石头各有专属样式。
- **实时牌型评估栏**：选中牌后即时显示牌型 + 基础筹码×倍率 + 等级（不计小丑），所见即所打。
- 隐藏实体剥离可交互标签，避免回合/商店/补充包跨阶段误点。
- 新增消耗品行展示（塔罗/星球/幻灵）。
- 公共 API 不变，`GameSession`/`BoardListener` 无需改动；射线交互、节流、音效沿用。
