# Balatro v0.3.2 — 开局展示本局信息（新手友好）

> 0.3.1 的功能补丁。基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。

## 改动

### 开局在聊天框给出本局完整信息

`/balatro play ...` 开局时，除了手牌简报，额外在聊天框列出本局信息，便于新手快速了解：

- **标题行**：种子 · 牌组名 · 赌注名 · 挑战名（若有）
- **牌组效果**：所选牌组的描述（如「红色牌组：每回合弃牌次数 +1」）
- **赌注效果**：所选赌注的描述
- **挑战效果**：挑战模式的描述（若有）
- **开局持有**：本局初始拥有的优惠券 / 消耗品（如魔法牌组的「水晶球(券) · 愚人 · 愚人」、幽灵牌组的「妖术」、黄道牌组的 3 张券等；无则省略）
- **第 1 底注 Boss**：名称 + 效果，让玩家提前规划
- **操作提示**：右键选牌/出牌/弃牌，`/balatro help` 查看玩法

此前仅发"种子/牌组/赌注"的 key 名，无效果说明。

## 测试

- `./gradlew test`：70 测试全过（本改动在命令层，未改引擎逻辑）。

## 构建

`./gradlew build` → `build/libs/balatro-0.3.2.jar`（JDK 21，paper-api 1.21.11）。
