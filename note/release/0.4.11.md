## 审计确认安全的路径（留档）

### 52 个消耗品效果（对照 REF engine.js applyConsumable 逐项）

- **塔罗 22**：fool 递归（用被复制 key 建流 + useSeq 再增，与 REF 一致）、magician/empress/hierophant
  （至多 2 张）、priestess/emperor（生成消耗品，满槽 break；emperor 抽到自身 continue 仍耗流）、
  lovers/chariot/justice/devil/tower（恰好 1 张，stone 置 rank=0/suit=-1）、hermit（min(20,money)）、
  wheel（doubleProb 翻倍、成功才 pick joker+edition）、strength（2<=rank<14 才+1）、hanged（销毁+补满）、
  death（恰好 2 张复制，不拷 chipBonus 与 REF 一致）、temperance（min(50,售价值和)）、
  star/moon/sun/world（至多 3 张改花色，stone 跳过）、judgement（随机小丑）。
- **幻灵 18**：familiar/grim/incantation（销毁 1 + 生成 N，randomPlayingCardRaw=rpc 流与 Java 一致、
  enh 均匀抽取）、talisman/dejavu/trance/medium（蜡封）、aura（均匀版本）、wraith（金钱归零+稀有小丑，
  满槽不补正与 REF 同）、sigil/ouija（改花色/点数，stone 跳过）、hex/ankh（保留 1 非永恒，ankh 复制）、
  cryptid（复制 2 张 + trimHand）、immolate（销毁 5 +$20）、soul（传奇小丑）、blackhole（全牌型+1）、
  ectoplasm（无版本者→负片，手牌-1）。
- **辅助函数对齐**：`randomPlayingCardRaw`=stream("rpc")+range(2,14)/range(0,3) 与 Java 一致；
  `destroyRandomHandCards`=stream("destroyhand")+pick(hand)+splice+destroyCard+drawUpTo（Java 的
  refillHand 多一次 sortHand，仅显示用且与最终 sortHand 冗余，harmless）；`trimHand` 逐字一致
  （超 handSizeRound+3 弹尾入弃牌堆）。

## REF-inherited 已知项（保持对齐，不改）

  净效果一致，商店过滤亦正确（均不再出现）。
