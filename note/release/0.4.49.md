# Balatro v0.4.49 — P11 性能优化：流创建与构局残留（二期收官）

> 基线：Minecraft 1.21.11 / Paper API（Papo 服务端）。性能战役第二期第 4 轮（收官）。

## 改动（行为零变化）

1. **流创建零字符串化**：`Rng.prefixHash(runSeed)` 预折叠 `runSeed+"::"` 前缀态（每局一次），
   `streamFrom` 增量折叠流名——FNV-1a 左到右折叠可分段，与 `makeStream` 拼接哈希**逐位等价**。
   新增 `RngStreamPrefixTest`（7 种子×12 流名×64 值逐位断言+前缀态恒等式）作种子复现守门。
2. `RunState.<init>` 遍历共享 `Data.HAND_TYPES` 替代每次 `HandType.values()` 新数组。
3. `StreamSource.streams` 预置容量 32。
4. （实验回退）商店小丑池暂存：分配 −13% 但孤立 A/B 四对 min 一致 +4%——按红线回退，
   负结果存证于报告。
