# note — Balatro-Plugin 项目笔记

本文件夹存放本项目的**要点分析**与**开发规范**，便于版本管理与回溯。

参考资料 `REF/` 在 `.gitignore` 中被忽略（仅本地存在），不在仓库内；
笔记中引用 `REF/...` 路径时，请到本地 `REF/` 目录下查找对应文件。

## 目录结构约定

```
note/
├── README.md              本文件：索引 + 目录使用规范
├── 项目概览.md            项目目的、技术栈结论、要点总览
├── 开发规范.md            构建 / 版本 / Git / 编码规范（含待决策项）
├── references/            三个参考资料的分析要点
│   ├── doudizhu-架构.md   参考插件 doudizhu 的实现方式分析
│   ├── balatro-规则.md    要实现的目标玩法：Balatro（小丑牌）规则提取
│   └── papo-服务端.md     插件运行的服务端：Papo（Paper 1.21.11 fork）说明
├── release/               各版本改动说明，文件名 = 版本号，如 0.1.0.md
└── report/
    └── perf/              性能测试报告（如有）
```

## 约定

- **版本发布说明**：每个发版写 `note/release/<版本号>.md`，记录基线、改动、兼容性、验证。
- **性能报告**：放 `note/report/perf/`，文件名带日期与主题，如 `2026-08-09-xxx.md`。
- **要点 vs 规范**：`references/` 与 `项目概览.md` 记录"是什么/为什么"（事实）；
  `开发规范.md` 记录"怎么做"（约定与决策），其中尚未拍板的条目标注 `[待决策]`。
- 该约定参考 Papo 服务端自身的 `REF/Papo/note/` 目录组织（release / report/perf 等）。
