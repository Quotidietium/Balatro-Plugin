## 三、方法学资产（三期新增）

1. **TLAB 经济学定则**（P12 三次确认并扩展）：百元素级列表物化 ~0.1ns/B；复用、两趟
   遍历、索引技巧均须先赢过这笔账。分配削减 ≠ 时间收益。
2. **打包结构配套谓词**（P13）：位打包后 `getter()==X` 变解码数组取——热路径必须配
   位段 int 比较谓词（`isEnh` 等），否则解码成本反噬。
3. **草稿数组长度契约**（P15 事故）：消费方按全长迭代的草稿数组，长度必须恰为语义长度
   （固定 5 长 window 在四指 4 长窗口残留脏值，症状随调用史漂移——ROYAL+5 / SFLUSH 两态）。
4. **原语数组池化成立判据**（P15）：纯原语（无引用写屏障）+ 每次全量重写（缓存必热）+
   无重入——与 P10/P11 失败的引用列表池化划清边界。
5. **discard 套件伪影三现**（P6/P13/P15）：discard 排 playHand 后受 JIT 布局影响，
   套内数字系统性失真——正式判读一律孤立 A/B。
6. **长时窗漂移**（三期终局）：连续基准多小时后跨窗漂移可达 ±30%，best-of-3 的
   min-of-medians 假设（噪声只增大时间）在跨窗场景失效——终局测量须严格逐次交替，
   并以分配确定性为结构性证据。

## 四、红线执行记录

1. **种子复现**：P14/P15 流名分段折叠附逐位等价守门（`RngSegmentedStreamTest` 6 用例，
   含 foldInt 边界与 MIN_VALUE 事故用例）；流名全量清点（R106）同步扩展分段入口。
2. **测试**：463→474（差分等价/打包守门/分段流守门/清点扩展）；每轮 clean build 全过。
3. **sinkΔ**：P15 与三期终局逐场景增量逐位一致（终局含 11/11 场景）。
4. **API**：纯新增（Card 谓词、RunState.streamUse/streamPack/streamRound）；既有公开签名零变化。
