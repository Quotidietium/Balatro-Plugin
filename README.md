# Balatro — Minecraft 小丑牌插件

在 Minecraft 中游玩《小丑牌》(Balatro) 的扑克构筑 Roguelike：打牌计分、收集小丑与消耗品、挑战 Boss 盲注，通关 8 个底注。

## 环境要求

- **Minecraft 1.21.11**（Paper 或 Papo 服务端）
- **Java 21**

## 安装

1. 将 `balatro-0.2.6.jar` 放入服务端的 `plugins/` 目录。
2. 重启服务器。

## 开始一局

```
/balatro play [种子]
```

执行后，你面前会生成一张专属全息牌桌（仅自己可见，他人看不到）。

## 怎么操作（全息牌桌）

面对牌桌，用**右键**点击牌面即可，无需任何指令：

| 操作 | 作用 |
|---|---|
| **右键** | 使用 / 操作（选中手牌、购买商品、使用消耗品、出售小丑、出牌、弃牌…） |
| **Shift + 右键** | 查看该卡的详细简介（显示在聊天框） |

> 进入商店或开启补充包时，所有卡的简介会自动列在聊天框，方便你判断要买/选哪张。

## 一局怎么玩

1. **出牌**：右键选中手牌（牌会上移高亮）→ 右键「出牌」按钮计分。
2. **达成目标分**即通过当前盲注，进入**商店**。
3. 在商店右键购买 **小丑 / 消耗品（塔罗·星球·幻灵）/ 补充包 / 优惠券**，强化你的牌组。
4. 继续挑战下一个盲注（小→大→Boss），通过 **8 个底注（ante）** 即通关。

## 常用命令

全息点击是主要玩法，命令作为备用：

| 命令 | 说明 |
|---|---|
| `/balatro play [种子]` | 开始一局（别名 `/blt`、`/joker`） |
| `/balatro quit` | 放弃当前局 |
| `/balatro status` | 查看当前局面 |

## 权限

- `balatro.play`（默认：所有人）— 开始 / 退出一局
- `balatro.admin`（默认：管理员）— 管理操作

## 可选集成

- 安装 **Vault** 后自动接入服务器经济。
